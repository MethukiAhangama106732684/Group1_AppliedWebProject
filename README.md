# Group1_AppliedWebProject
Group1 Applied Web Project

This website belongs to IRONGATE Cybersecurity. A company that dedicates itself to protecting businesses, people and data. A main aspect of this page that the user can focus on is the fact they are currenlty in their hiring stage looking for newcomers. The positions vacant at the moment can be viewed on the Jobs page. Applications for jobs of the user's liking can be made using the form on the Apply Here page. To get to know more about the company and its current members the user can visit the About the Team page.

Technologies used: HTML, CSS, GitHub, Jira

Link to GitHub: https://github.com/MethukiAhangama106732684/Group1_AppliedWebProject
Link to Jira: https://methukiahangama.atlassian.net/jira/software/projects/G1AWP/boards/35/backlog

Note: the website was made more accessible and inclusive by:
- having a strong colour contrast between text and background colours
- using a font over 16px at all times 
- using only sans serif fonts to accomodate people with dyslexia
- having text hierarchy to clearly address headings
